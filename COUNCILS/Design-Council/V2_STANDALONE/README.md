# Design Council V2 — Standalone

Atomic, portable Design Council test target.

Inputs: Concrete Product Definition + Feasibility Assessment + Pre-Planning assessment/decision + human authorization.

Outputs: PRD.md + FRD.md + TRD.md.

PM: Capability → Epic → Version.
Downstream Product Owner: Epic → User Story → Acceptance Criteria.

No runtime dependency on SHARED/, AGENTS/, Orchestrator, or another council.
