# Pre-Planning V2 — Standalone Council

Portable, independently testable adaptation of the original CodeFoundry Pre-Planning logic.

Lifecycle:
Concrete Product Definition → Feasibility → Pre-Planning → Human Authorization → Design Council

Pre-Planning does not redefine the product, redo technology research, redo feasibility, choose architecture, decompose epics, or write PRD/FRD/TRD.

Runtime outputs:
pre-planning-assessment.md
pre-planning-decision.md
