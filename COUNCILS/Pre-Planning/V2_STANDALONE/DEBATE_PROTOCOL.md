# Debate Protocol — Pre-Planning V2

## Roles
Advocate — strongest evidence-based case for progression.
Skeptic — strongest evidence-based case against.
Value & Necessity Assessor — evaluates meaningful value and necessity without redoing technical feasibility.
Risk & Evidence Assessor — tests evidence sufficiency and decision-changing uncertainty.

## Sequence
1. Read complete inherited package.
2. Each role states position with evidence.
3. Roles challenge material claims.
4. Synthesizer resolves to one verdict.
5. Independent critic checks for silent scope change, duplicated upstream work, unsupported certainty, and missing evidence.
6. Revise if needed.
7. Produce the two authoritative artifacts.

No forced consensus: use NEEDS_MORE_EVIDENCE when evidence is insufficient.
