# Runtime Contract — Pre-Planning V2

## Entry
Require complete Concrete Product Definition plus appended Feasibility Assessment and evidence that both upstream gates completed. Missing or incomplete input is an invalid run.

## Evaluate
- product value and intended outcome
- necessity and problem significance
- value relative to established effort/conditions
- evidence strength
- downside/risk
- adoption/distribution context where relevant
- alternatives where evidence exists
- personal, hobby, learning, experimental, portfolio, or commercial value according to confirmed context
- material uncertainty
- whether Design Council progression is justified

## Do not redo
- Product Definition
- technology research
- hardware/API/hosting feasibility
- technical architecture
- epic decomposition
- PRD/FRD/TRD

## Evidence labels
VERIFIED / USER-CONFIRMED / INHERITED-FROM-FEASIBILITY / ENGINEERING-INFERENCE / UNVERIFIED

## Human gate
System verdict is not authorization.
