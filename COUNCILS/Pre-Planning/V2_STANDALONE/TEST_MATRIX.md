# Test Matrix — Pre-Planning V2

## Hard invariants
1. No run without Concrete Product Definition + Feasibility.
2. No silent product meaning/scope change.
3. No duplicated Feasibility.
4. No architecture instead of progression judgment.
5. Preserve personal/hobby/experimental value context.
6. Do not force commercial ROI when inappropriate.
7. Do not invent evidence.
8. Surface material uncertainty.
9. NEEDS_MORE_EVIDENCE names decision-changing evidence.
10. Return-to-upstream verdicts name the reason.
11. GO explains why progression is justified.
12. Both authoritative artifacts exist.
13. Human authorization is explicit.
14. Upstream context is passed intact.

## Adversarial families
Technically feasible/low value; valuable/conditional; hobby; learning; portfolio; commercial; strong incumbent; weak market evidence; API-dependent; hardware-constrained; privacy-constrained; expensive-at-scale; tiny audience; large/high-complexity; ambiguous meaning; contradictory constraints; uncertain distribution; simple/strategically weak; difficult/uniquely valuable; deliberate non-goals; future-extension leakage.

Run mutation tests changing one material fact at a time.
