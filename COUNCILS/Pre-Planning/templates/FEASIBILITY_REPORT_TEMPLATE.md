# Feasibility Report — Template

Produced by: Feasibility & Cost Assessor role
(`roles/Feasibility-Cost-Assessor.md`). Always created — see "Fast-path"
below. Never omitted.

## Header (always filled)

- Project / idea reference (`idea.md` link)
- Date
- Path taken: **FULL** or **FAST-PATH**
- If FAST-PATH: reason (same signal named in the Header of
  `MARKET_RESEARCH_TEMPLATE.md` for this project)

## Fast-path rule

All four dimensions below are still present in the document on
fast-path. Each is filled with:
`Not assessed in full — [reason from Header]. A rough personal-use cost
estimate is still given below; the at-scale estimate is skipped and
marked accordingly.`

Industry practice treats skipping any of the four core dimensions
(market, technical, financial, operational) as an incomplete
assessment — fast-path does not delete a dimension, it narrows it.

## Sections (full path)

### 1. Technical feasibility
Can this be built with realistically available tools/skills/time? Name
the single biggest technical unknown that could invalidate the estimate
(per `roles/Feasibility-Cost-Assessor.md` Rule 3).

### 2. Economic feasibility — cost at multiple scale points
- Personal / low-usage cost estimate
- Realistic growth-scenario cost estimate
- Cost-benefit summary against the Advocate's claimed value (referenced,
  not re-argued here)

### 3. Operational feasibility
Can this actually run day to day at the scale intended — who
maintains it, what breaks first, does it assume operational capacity
(`COUNCILS/Design-Council/HARD_CONSTRAINTS.md` category 13) that doesn't
exist?

### 4. Risk register (technical/cost risks only — not market risk,
that's the Skeptic's pre-mortem)
Rated list: risk, likelihood, impact, and whether it's the kind of
unknown that widens the cost estimate materially.

### 5. Reuse-adjusted estimate
If Market-Research's Repo Analyzer output (§4 of that template) found a
usable candidate, state how adopting/adapting it would change this
estimate versus building from scratch — a comparison, not a silent
substitution.

### 6. Recommendation to Advocate/Skeptic
One paragraph: what these numbers mean for the debate.
