Split from the original single `Product` agent per the industry-standard
PM/PO distinction: Product Manager owns strategy-level decomposition
(receiving Pre-Planning's verdict, breaking the idea into epics).
User-story and acceptance-criteria detail work is `AGENTS/Product-Owner/`.
