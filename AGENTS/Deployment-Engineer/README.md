# Deployment Engineer

This folder is a directly testable CodeFoundry agent unit. Its
`UNIT.json` is the machine-readable test boundary.

Fills the `DevOps / Release Worker` entry that
`SHARED/WORKER_SCOPE_REGISTRY.md` previously left `SCOPED` — built per
an explicit instruction covering how `dev_<project>`, `test_<project>`,
and `prod_<project>` are promoted to separate GitHub repositories, and
the one-sanctioned-download-point rule.
